# Scrybe Web

Frontend de Scrybe desarrollado con React, TypeScript y Vite.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- i18next

## Desarrollo

```bash
npm install
npm run dev
```

## Estructura

```text
src/
  app/
  features/
  shared/
```

## Notas

- Autenticación basada en Supabase Auth (JWT)
- Soporte de internacionalización (ES / EN)
- Arquitectura modular por features
